## Two GitHub repositories to create

1. `itsevawolf/itsevawolf` — **Public**. GitHub uses its README.md as your profile page. Upload `itsevawolf/README.md`.
2. `itsevawolf/squady-lab` — **Public**. Upload the files from `squady-lab/` to the repo root, then enable GitHub Pages using `docs/PUBLISH.md`.

These are **new** repositories. Do not change the visibility of `squadmate-platform`, `SquadMateIO/api`, `SquadMateIO/app-angular`, `SquadMateIO/docker`, or `.github-private`.

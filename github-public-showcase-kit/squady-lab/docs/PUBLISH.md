# Publishing checklist

1. Create a **public** GitHub repository named `squady-lab` under `itsevawolf`. Initialize it empty.
2. Upload this folder's files to the repository root (README.md, index.html, styles.css, main.js, assets/).
3. Open the repository's **Settings → Pages**. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. Verify https://itsevawolf.github.io/squady-lab/ is accessible, interactive, mobile-friendly, and that no client data is present.
5. Only then share the public demo on X. Link to the lab, not the private app repository.

The SQUADMATE platform source, Stripe setup, personal passwords, API endpoints and customer work stay private. Character artwork included here is intentionally reduced-resolution for demo purposes and is not licensed for reuse.
